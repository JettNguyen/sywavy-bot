SyWavy Bot

A private assistant for the artist SyWavy and his team. It helps them decide what to post and shows them how each post did.

What it does

  • Plans posts. It picks which finished clip goes out on which day and writes the on-screen hook and captions for it.
  • Reads the numbers. It reads how each post did on YouTube, Instagram and TikTok straight from those platforms, so nobody has to screenshot stats.
  • Drafts comment replies. It suggests a reply to new comments in SyWavy's voice. A reply is posted only when someone on the team taps Post.

Who it is for

It connects only to SyWavy's own accounts: YouTube @sywavy, Instagram @sywavvy and TikTok @sywavy. It is not offered to anyone else, and there is nothing to sign up for.

SyWavy Bot uses YouTube API Services.
